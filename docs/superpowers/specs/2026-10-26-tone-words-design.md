# Тренировка тонов (№15) по словам HSK 2.0 — проектный замысел

Замысел согласован с автором 26.10.2026.

## Задача

Задание 15 — сочетание тонов в слове из двух-трёх иероглифов. Банк ФИПИ даёт на него 28 заданий,
этого мало, чтобы выучить тоны. Нужна отдельная тренировка: большой словарь слов HSK 2.0 уровней 1–4,
у каждого слова четыре сочетания тонов (одно верное), круги по 10, 30, 50 или любому числу слов,
ошибки круга можно повторить — как в практике.

## Решения

- **Слова** — HSK 2.0 (старая версия), уровни 1–4 (150 / 300 / 600 / 1200 слов нарастающим итогом),
  только слова из 2–3 иероглифов (835 слов). Список — таблицы автора (`HSK1–4.xlsx`, «Лексика / HSK по темам»);
  перевод — оттуда же. Уровень слова — наименьший, где оно встречается.
- **Тоны** — из поля «Транскрипция» колод Anki автора; слова, которых там нет, дописываются вручную
  и проверяются так же. Как в правиле «Тоны в словах»: словарный тон каждого слога, `0` — лёгкий тон,
  изменения при чтении (3+3, 一, 不) не учитываются.
- **Слово не берётся**, если ответ можно оспорить: источники расходятся в лёгком тоне (`kùnnan` / `kùnnán`),
  у слова два чтения, пиньинь не делится на слоги по числу иероглифов. Такие слова — в отчёте
  `data/review/tones-report.md`, решает автор. Слово, которое уже есть среди заданий №15 ФИПИ, не берётся:
  тренировка не должна подсказывать ключ.
- **Варианты** — четыре, один верный. Неверные собираются так же, как в заданиях ФИПИ: меняется один слог,
  порядок тонов или тон заменяется лёгким. Выбор случайный, но зависит только от слова — сборка повторима.
  Две записи одного слова не могут совпасть.
- **Разбор** собирается из данных слова: пиньинь, перевод, тон каждого слога, а у каждого неверного
  варианта — какой слог и почему не совпал. Общих фраз нет.
- **Принятие**: черновик (`draft`) → ревью двух независимых агентов → `accept_tones.py`, как у заданий
  банка. На сайт идут только принятые слова; `--drafts` показывает все. Отпечаток слова
  (иероглифы, пиньинь, тоны, перевод) входит в принятие — правка останавливает сборку.
- **Круги** — режим «Практика» уже умеет: раунд, «Повторить ошибки раунда», интервальное повторение
  (1, 3, 7 дней), прогресс в том же хранилище. Тренировка тонов использует ту же сессию (`progress.round`
  с пометкой `mode: "tones"`) и тот же код карточки и разбора; ответы пишутся в `progress.questions`
  под своими ID `w15-…`. Версия прогресса не меняется: пометка — необязательное поле сессии.
- **Экран** — вкладка «Тоны»: уровень HSK (1–4), длина слова (2 или 3 иероглифа), состояние (все, новые,
  ошибки, на повторение), размер круга теми же кнопками, что в практике. Слово крупно, без пиньиня;
  после ответа — пиньинь, перевод и разбор.
- **Не делаем**: слова не попадают в «Практику», «Вариант», «Банк» и отчёт учителю (их ID учитель не
  разберёт); ссылок на круг тонов нет; ID слов не мешают ID заданий банка.

## Чего не делаем

- Не заводим слова в едином банке заданий и не правим его: тренировка — отдельный слой данных тренажёра.
- Не берём HSK 3.0 и слова из одного иероглифа.
- Не показываем пиньинь до ответа.

## Данные

- `sources/words/hsk2-words.json` — выписка из таблиц и Anki (`scripts/extract_words.py`, один раз):
  слово, уровень, перевод, варианты пиньиня из Anki. Руками не правится; рядом `README.md` — откуда.
- `data/words/overrides.json` — решения по слову: `{ "слово": { "pinyin": "…", "why": "…" } }` (чтение
  вписано вручную) или `{ "skip": true, "why": "…" }`.
- `data/tone-words.json` — результат `scripts/build_tones.py`: слова с тонами, статусом и отпечатком.
  Руками не правится.
- `data/review/tones-report.md` — отчёт: не взятые слова и почему.
- `scripts/tones.py` — чистые функции (слоги, тоны, варианты, разбор), общие для сборки и тестов.
