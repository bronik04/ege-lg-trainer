# Главная практики — согласованный вариант C

Автор выбрал макет C и 07.11.2026 разрешил перенести его на «Практику», проверить локально
и сразу опубликовать. «Тоны» и остальные экраны сохраняют прежний вид и поведение.

- Убрать вводный блок «Практика ЕГЭ» с пояснениями. Верх: заголовок выбранной подборки,
  краткое число заданий и доступных вопросов, справа «Начать раунд»; продолжение начатого
  раунда и предупреждения о замене сохраняются.
- Настройки на компьютере — две группы в сетке 1:2. «Какие задания» — обычный select,
  «Размер раунда» — шесть прямоугольных значений и поле своего числа с кнопками ±.
  Стрелка select — с отступом 14 px справа; на телефоне группы стоят друг под другом.
- Оглавление заданий сохранить. Правила появляются при выборе номера; пустую подсказку
  о выборе номера не показывать.
- Источники — компактное раскрытие «Источники: все» с прежними фильтрами внутри.
  «Снять фильтры» появляется при активном выборе; размер раунда не сбрасывает.
  «Поделиться настройками» раскрывает прежнюю ссылку с ясным пояснением, что случайные
  задания у каждого свои.
- Дизайн-система «Тушь и киноварь», размеры карточек, данные, URL, ключи прогресса,
  выбор и прохождение раунда, мобильная нижняя кнопка и клавиатура сохраняются.

Рассмотрены: A — две строки капсул; B — размер у кнопки запуска; C — компактный select
и прямоугольные кнопки; D — две строки сегментов. Выбран C с поправкой стрелки.
