# Practice home layout Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved plan inline. Do not dispatch agents without the author's consent.

**Goal:** Перенести одобренный вариант C на экран настройки практики и опубликовать его.

**Architecture:** Обычный рендер DOM в `src/app.js`, без обработчиков прототипа и MutationObserver.
Изменения стилей ограничены `.practice-setup`; общий контрол тонов остаётся прежним.

**Tech Stack:** Vanilla JavaScript/CSS, Python static build, Playwright/Chrome, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-07-practice-home-layout-design.md`.

## Global Constraints

- Только «Практика»; «Тоны» и прочие экраны сохраняются.
- Стрелка select — с отступом 14 px справа.
- Не изменять данные, токены системы, URL и формат прогресса.
- Не публиковать незавершённые правки банка из исходной рабочей папки.

## Review Focus

- Смена состояния в select сохраняется после перезагрузки и управляет составом раунда.
- Выбор источника не закрывает раскрытие при перерисовке и корректно сужает подборку.
- Число раунда, краткая подпись, ссылка и нижняя кнопка обновляются вместе.
- Длинная подборка, предупреждение и продолжение помещаются на ширинах 320–1200 px.
- После перехода на «Тоны» новые стили и select практики отсутствуют.
