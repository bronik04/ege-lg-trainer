# Training rounds Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Do not dispatch agents without the author's consent.

**Goal:** Два режима в практике и тонах, отложенный повтор и доступное управление на итогах.

**Architecture:** Общие чистые функции очереди в `src/logic.mjs`, текущий DOM-рендер в `src/app.js`,
небольшие стили в существующей системе. Без сторонних зависимостей и изменений контента.

**Tech Stack:** JavaScript, CSS, Python static build, Node tests, Playwright/Chrome, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-09-training-rounds-design.md`.

## Global Constraints

- Ошибка возвращается один раз через пять других карточек либо в конце раунда.
- Первая попытка определяет исходный балл; повторы имеют отдельные результаты.
- Оба раздела получают переключатель; «Тест» по умолчанию; полный вариант не становится тренировкой.
- Миграция прогресса 1/2 → 3 с резервной копией, сохранением вариантов и текущих раундов.
- Банк, дизайн-токены, формат отчёта учителю не меняются.

## Review Focus

- Несколько ошибок, ошибка на последнем шаге и повторная ошибка не создают бесконечный цикл.
- После перезагрузки на разборе или повторе не теряются очередь, ответ и первая оценка.
- Снятие задания из банка не сдвигает ответы к другому вопросу и не оставляет его в очереди.
- Смена настройки не переделывает начатый раунд; перезапуск и ссылки сохраняют нужный режим.
- Кнопки итогов доступны до списков; телефон, клавиатура, тоны, отчёты и старые файлы работают.
