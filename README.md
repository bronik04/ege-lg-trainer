# Лексика и грамматика ЕГЭ — китайский язык

[![Deploy to GitHub Pages](https://github.com/bronik04/ege-lg-trainer/actions/workflows/pages.yml/badge.svg)](https://github.com/bronik04/ege-lg-trainer/actions/workflows/pages.yml)

**Сайт:** https://bronik04.github.io/ege-lg-trainer/

Тренажёр заданий 15–27 ЕГЭ по китайскому языку. Ученик читает правило, проверяет себя
коротким вопросом, решает задания из открытого банка ФИПИ и собирает полный вариант
раздела 3 — по одному заданию на каждую позицию 15–27. После ошибки он видит, почему
не подходит именно выбранный вариант, верный ответ, правило и контрастный пример.

Страница самодостаточна: `dist/index.html` работает без сервера и без сети.
Прогресс хранится в браузере ученика; перенести его на другое устройство можно файлом
(«Банк и ошибки» → «Сохранить в файл»). Исправленная ошибка возвращается на повтор через
1, 3 и 7 дней, а банк показывает слабые темы и правила к ним.

## Для учителя

Задание классу — ссылкой, без аккаунтов:

- **Подборка** — «Практика ЕГЭ» → выбрать темы, номера и размер раунда → «Ссылка на
  подборку». Каждому ученику задания выпадут свои. Вид ссылки:
  `…/#/practice?topics=adverbs&tasks=22&size=10`.
- **Одни и те же задания** — пройти раунд и на его итоге взять «Ссылку на эти задания»
  (`…/#/practice?ids=…`).
- **Один вариант на весь класс** — завершить полный вариант и взять «Ссылку на этот
  вариант» (`…/#/variant?ids=…`). Если у ученика начат свой вариант, страница спросит,
  заменить ли его.

Результаты ученики видят у себя; сервера, который собирал бы их учителю, нет.

## Как устроены данные

    sources/constructor-bank/   снимок банка ФИПИ из «ЕГЭ Конструктора» (не редактируется)
    sources/generated/          партии новых заданий (навык ege-chinese или Claude)
    data/raw/                   импорт без правки текста
    data/authored/task-NN.json  разборы, темы и правила заданий (черновик → принято)
    data/topics.json            темы; номер задания и тема — разные признаки
    data/rules.json             карточки правил
    data/rule-checks.json       вопросы на понимание правил
    data/questions.json         канонический банк со статусом каждого задания
    data/review/                отчёты: импорт, дубликаты, покрытие, очередь проверки

Статусы задания: `imported` — разбора нет; `draft` — разбор написан, не принят;
`ready` — принят и попадает к ученику; `conflict` — спорный ключ; `excluded` — повтор.

## Как добавить и проверить задания

1. Новые задания ФИПИ — в Конструктор, затем `python3 scripts/snapshot_constructor.py`.
   Новые задания (от навыка или написанные Claude по команде автора) — файлом в
   `sources/generated/` (формат — в `sources/generated/README.md`).
2. Пересобрать банк: `npm run data` (импорт → сборка банка → проверка).
3. Написать разборы волной: `python3 scripts/add_explanations.py wave.json`.
4. Прочитать `data/review/queue.md` или открыть страницу проверки
   `python3 scripts/build_site.py --drafts` → `review-build/review.html`.
5. Принять проверенное: `python3 scripts/accept.py ID …` (или `--task 20`), затем
   снова `npm run data`. Сколько готово по позициям и темам — `data/review/coverage.md`.

Под каждым разбором есть ссылка «Сообщить на GitHub»: она
открывает новый issue в этом репозитории с ID задания, условием, выбранным ответом и
ключом. Сообщения учеников — в
[issues](https://github.com/bronik04/ege-lg-trainer/issues); спорный ключ отмечается
`keyConflict`, как и при чтении банка.

## Сборка и тесты

    npm ci                                    # playwright-core для браузерного теста
    npm run data                              # банк и проверка данных
    npm test                                  # тесты Python и Node (браузерный — если есть Chrome)
    python3 scripts/build_site.py             # dist/index.html

## Публикация

`.github/workflows/pages.yml` при каждом push в `main` пересобирает банк, прогоняет
проверку и тесты и только после этого публикует `dist/` на GitHub Pages:
https://bronik04.github.io/ege-lg-trainer/. Если закоммиченные данные разошлись с
пересборкой, публикация останавливается — запустите `npm run data` и закоммитьте.
