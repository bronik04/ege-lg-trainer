# Сгенерированные задания

Сюда кладутся партии заданий, подготовленных навыком `ege-chinese`. После импорта
они попадают в банк с пометкой `origin: generated` и видны ученику как «Новое задание»,
но только после того же принятия разборов, что и задания ФИПИ.

## Два вида партии

**JSON** — `<дата>-<тема>.json`:

```json
{
  "generator": "навык ege-chinese",
  "specVersion": "ЕГЭ 2026",
  "tasks": [
    {"taskNumber": 22, "stem": "他昨天来了，今天___来了。", "options": ["还", "再", "又", "就"], "key": 3}
  ]
}
```

`key` — номер верного варианта с единицы (как в `series.json` навыка). У заданий 20 и 21
три варианта, у остальных четыре. Для задания 26 фрагменты пишутся в `stem`:
`"A) …\nB) …\nC) …"`.

**Markdown** — ответ навыка как есть (`<дата>-<тема>.md`): задания «**22.** …», строка
вариантов «1) …  2) …», ключи «**22 — ответ: 3**». Добавьте в начало файла строку
`Спецификация: ЕГЭ 2026` — без неё партия не импортируется.

## Путь до ученика

1. `python3 scripts/import_generated.py` → `data/raw/generated.json`, замечания —
   в `data/review/generated-import.md`.
2. `python3 scripts/build_bank.py` — задание с тем же условием, что у задания ФИПИ,
   исключается как повтор.
3. Разборы каждого варианта — волной через `scripts/add_explanations.py`.
4. Проверка автором по `data/review/queue.md`, затем `scripts/accept.py`.
