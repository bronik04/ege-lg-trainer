# Слова HSK 2.0 для тренировки тонов

`hsk2-words.json` — выписка слов уровней 1–4 из 2–3 иероглифов (`scripts/extract_words.py`):

- слова, уровень и перевод — таблицы автора `HSK1–4.xlsx` (Яндекс.Диск, «Китайский язык / 02-Навыки / Лексика /
  HSK по темам»), только первый лист каждой книги: на остальных столбцы съехали;
- пиньинь — тот же столбец таблиц и поле «Транскрипция» колод Anki автора (записи сверяет `build_tones.py`);
- контрольные суммы таблиц лежат в поле `source`.

Руками файл не правят: обновили таблицы или Anki — запустите `extract_words.py` заново. Решения по отдельным
словам (чтение, перевод, не брать) — `data/words/overrides.json`.
