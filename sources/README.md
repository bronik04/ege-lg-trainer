# Первоисточники

## bank/ — выгрузка единого банка заданий (с 24.10.2026 — единственный источник)

- **Откуда.** Единый банк заданий ЕГЭ (`~/Documents/Projects/ege-task-bank`, данные на Яндекс.Диске):
  `npm run bank -- export-sites lg <файл>` — задания 15–27 в состоянии «проверено» или «отборное» без
  пометки «только для уроков»; у каждого — ID задания в тренажёре (`lgIds`), если он уже есть.
- **Как обновить.** `python3 scripts/snapshot_bank.py <файл>` кладёт выгрузку в `bank/export.json` и пишет
  `bank/manifest.json` с контрольной суммой. Конвейер читает только снимок: сайт собирается в GitHub
  Actions, где Диска нет. Править снимок руками нельзя — сверка суммы его отвергнет.

Файлы здесь не редактируются: это снимки, из которых конвейер собирает банк.
Контрольные суммы снимка банка — в `manifest.json`, тест сверяет их при каждом прогоне.
