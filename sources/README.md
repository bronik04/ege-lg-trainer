# Первоисточники

Файлы здесь не редактируются: это снимки, из которых конвейер собирает банк.
Контрольные суммы снимка банка — в `manifest.json`, тест сверяет их при каждом прогоне.

## constructor-bank/ — задания 15–27 из банка ФИПИ

- **Откуда.** Банк приложения «ЕГЭ Конструктор» (`ege-chinese-constructor`), каталог
  `~/Library/Application Support/ege-chinese-constructor/bank/blocks`. Автор перенёс туда
  задания открытого банка ФИПИ; у всех блоков тег «Банк ФИПИ».
- **Как обновить.** `python3 scripts/snapshot_constructor.py` копирует блоки
  `grammar-15` … `grammar-27` байт в байт и переписывает `manifest.json`. Сам Конструктор
  не меняется. Дальше — `import_constructor.py` и `build_bank.py`.
- **Формат блока** (JSON, `schemaVersion: 1`): `type` = `grammar-NN` (номер задания),
  `codifierCodes`, `tasks[0].prompt` (условие), `tasks[0].options[]` (`id` — номер варианта
  с единицы, `text`), `tasks[0].positions[0].correct` (ID верного варианта), `tags`.
- **Что читается однозначно:** номер задания, условие, варианты в исходном порядке, ключ.
  У заданий 20 и 21 по три варианта, у остальных по четыре. Фрагменты A, B, C задания 26
  выделяются из условия (два вида записи: по строкам «A) …» и в одну строку «A … B … C …»).
- **Реквизиты источника.** ID задания в банке ФИПИ (тег `ФИПИ 3872A5`) и код элемента
  кодификатора (тег `КЭС ФИПИ 2.1.4`) есть только у 32 заданий, добавленных в сентябре 2026.
  У остальных источник — «открытый банк ФИПИ» без номера.
- **Чего нет в источнике:** года материалов (всем записям проставлен формат 2026),
  разборов, тем и правил. `codifierCodes` блока одинаковы у всех заданий одного номера —
  это код номера, а не темы конкретного задания.
- **Замечания** к отдельным записям (нестандартная запись чисел в №19, записи №24 в
  формате №23) — в `data/review/import-report.md`.
